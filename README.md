# Desenvolvimento Web II (DESWEB2)

Este repositório contém as atividades e projetos desenvolvidos na disciplina de Desenvolvimento Web II.

## 📁 Estrutura do Repositório

- **`express-bsi4/`**: APIs e aplicações desenvolvidas utilizando **Node.js** e **Express**.
- **`fastapi-bsi4/`**: APIs desenvolvidas utilizando **Python** e **FastAPI**.

## 🛠️ Tecnologias Utilizadas

- **Node.js** & **Express**
- **Python** & **FastAPI**
- **Bruno** (Cliente HTTP para testes de API)
- **Git** & **GitHub**
